# Costos Delibroaster

App de costeo de platos. React + Vite + Supabase.

## Correr en tu computador
1. Abre PowerShell en esta carpeta.
2. npm install      (solo la primera vez)
3. npm run dev
4. Abre http://localhost:5173

## Qué hay en este paso (2)
- Login con roles.
- Insumos: buscar, editar precio (con "X platos recalculados"), crear insumo nuevo
  con conversión de unidades (lb/kg -> gramos).
- Recetas y Sub-recetas: crear y editar, con ingredientes anidados.
- El encargado NO ve costos, márgenes ni precios de venta.
- Tablero del dueño: llega en el paso 3.

.env.local ya trae la conexión. No lo subas a internet (ya está en .gitignore).
